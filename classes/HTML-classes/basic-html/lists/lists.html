Listas en HTML

En HTML existen dos tipos de listas, las listas ordenadas y las listas desordenadas, el uso de una u otra dependera de lo que necesitemos listar.

Ejemplo de una lista ordenada

  1. Elemento 01
  2. Elemento 02
  3. Elemento 03

Ejemplo de una lista desordenada

  • Elemento 01
  • Elemento 02
  • Elemento 03
